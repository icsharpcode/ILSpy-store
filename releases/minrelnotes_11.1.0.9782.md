# New Features
* Emit C# 7.1 default literals where the context supplies the type
* Decompile C# 14 implicit span conversions (first-class span types)
* Decompile semi-auto properties with the C# 14 field keyword
* Bug fixes to the decompiler by fuzzing NuGet packages


For more details see https://github.com/icsharpcode/ILSpy/releases/tag/v11.1
